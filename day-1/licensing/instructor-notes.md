# Instructor notes — Licencování

## Go/no-go před během (od 2026-11)

- **T1 — Copilot in SharePoint / Skills na PAYG bez licence.** Před D1 přihlásit testovací studentský účet (Business Basic + PAYG) a ověřit: (a) otevře se Copilot in SharePoint na studentském webu, (b) jde vytvořit a spustit site skill, (c) personal skill.
  - **Funguje** → výklad: „v preview ověřeno, po GA stále funguje, MS dokumentuje jinak — docs vs. realita"; Skills lab D5 hands-on.
  - **Nefunguje** → výklad: „GA uzavřel preview cestu, platí docs (license-only)"; Skills a Copilot in SharePoint jedou jako instruktorské demo; upravit §5 ústně.
- **Cost management** v M365 AC: zkontrolovat, že instruktorská spending policy nemá zapnuté **Auto-apply new services** (jinak se do ní samy přidají Code/Autopilot apod.).

## Tripwires

- Mýtus „Skills jen pro E licence" — vyvrátit: gate je placená Copilot licence (i Business), ne tier. Zda je PAYG alternativou pro Copilot in SharePoint/Skills, rozhoduje výsledek T1 (v preview 2026-07-17 fungovalo, docs po GA říkají license-only).
- „Budget ≠ strop" platí jen pro původní Copilot PAYG. V Cost management (usage-based billing) strop je — nemíchat.
- „Credits nahradí licenci" — u Cowork, Advanced work v SharePointu a Code ne: Credits jsou navíc k licenci.
- „SharePoint Premium" jako deštník — rozpadlý. Trvat na aktuálních názvech.
